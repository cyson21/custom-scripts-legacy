# custom-scripts-legacy

맥북에서 쓰던 CLI 도구 스냅샷입니다. 유지보수하지 않습니다. 윈도우 포팅도 하지 않았습니다.

정본 git: https://github.com/cyson21/custom-scripts-legacy

| 폴더 | 무엇 |
|---|---|
| `ai-tool/` | Gemini CLI·Claude Code 세션을 한 TUI에서 관리 |
| `multi-agent-orchestrator/` | Gemini·Codex·Claude를 병렬로 돌리는 스웜 TUI |
| `arena/` | 다중 에이전트 교차 리뷰 bash 프레임워크 |

원래 macOS/Linux용입니다. API 키와 실행 로그는 넣지 않았습니다. 오케스트레이터를 쓸 때는 `multi-agent-orchestrator/.env.example`을 `.env`로 복사하세요.
