# multi-agent-orchestrator Operations Guide

이 문서는 `multi-agent-orchestrator` 프로젝트의 사람용 운영 메모입니다.
AI가 매 세션 바로 읽어야 하는 실행 규칙은 같은 디렉토리의 `AGENTS.md`에 두고, 배경 설명과 운영 절차는 여기 둡니다.

## 문서 역할
- `AGENTS.md`: AI 주입용 로컬 실행 규칙
- `AGENTS_OPERATIONS.md`: 사람용 운영 메모와 배경 설명

## 왜 분리했는가
- 이 프로젝트는 에이전트 시작 절차, 레거시 파일 취급, TUI 금지 규칙이 함께 얽혀 있습니다.
- AI는 실행 규칙만 짧게 읽는 편이 안정적이고, 사람은 배경 설명과 운영 의도를 별도 문서에서 보는 편이 이해가 쉽습니다.

## 운영 메모
- `workflow.py`는 레거시 파일로 취급하며 신규 진입점으로 사용하지 않습니다.
- TUI 변경은 수동 확인보다 헤드리스 검증 경로(`pytest`, 비대화형 스크립트)를 우선합니다.
