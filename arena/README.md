# 🏟️ Arena: Multi-Agent AI Code Review Framework

**Arena**는 여러 AI 에이전트(Claude, Gemini, Codex 등)를 활용하여 코드 작성부터 상호 리뷰, 피드백 자동 반영, 그리고 깔끔한 Git 커밋 관리까지 지원하는 강력한 자동화 프레임워크입니다.

## 🚀 핵심 기능

### 1. 지능형 워크플로우
- **전체 루프 (Full Loop)**: 에이전트별 독립된 Worktree와 브랜치를 생성하여 안전하게 AI 코딩 실험을 진행합니다.
- **즉석 리뷰 (Adhoc Review)**: 별도의 설정 없이 현재 작업 중인 브랜치의 차이점(Diff)을 즉시 추출하여 AI에게 리뷰를 요청합니다.

### 2. 리뷰 고도화
- **교차 리뷰 (Cross-Review)**: 한 AI가 짠 코드를 다른 AI가 검토하여 객관적인 품질 향상을 꾀합니다.
- **통합 리포트**: 여러 AI의 의견을 종합하여 최종적인 개선 방향을 제시합니다.
- **피드백 자동 적용 (Auto-Apply)**: AI의 리뷰 제안 내용을 현재 코드에 즉각적으로 반영(Patch)하는 기능을 제공합니다.

### 3. 사용자 경험 (UX)
- **TUI 가이드**: `gum` 기반의 대화형 인터페이스를 통해 단계별(Step-by-Step)로 작업을 진행합니다.
- **자동 모니터링**: 외부 터미널(iTerm2, tmux)에서 실행되는 AI의 작업 완료를 자동으로 감지하여 다음 단계로 넘겨줍니다.
- **라이브 대시보드**: 현재 Git 상태, 실행 중인 에이전트, RUN 정보를 한눈에 파악합니다.

### 4. 깔끔한 Git 관리
- **커밋 스쿼시 (Squash)**: 리뷰 과정에서 생성된 수많은 임시 커밋들을 하나로 병합합니다.
- **AI 메시지 재작성 (Amend)**: 수정 내용을 분석하여 컨벤션에 맞는 전문적인 커밋 메시지를 자동 생성하고 적용합니다.

## 🏗️ 디렉토리 구조

스크립트는 유지보수성과 확장성을 위해 모듈화되어 있습니다.

```text
arena/
├── agent_arena.sh      # 메인 실행 엔트리포인트
├── README.md           # 프로젝트 문서
├── lib/                # 기능별 모듈 (Libraries)
│   ├── core.sh         # 공통 유틸리티, 로깅, 검증
│   ├── agent.sh        # 에이전트 설정 및 속성 관리
│   ├── run.sh          # 실행 기록(Meta) 및 저장소 컨텍스트
│   ├── ui.sh           # 입력 인터페이스 및 UI Dispatcher
│   ├── report.sh       # 리포트 생성 로직
│   ├── cmd.sh          # 핵심 명령어 구현 (핵심 로직)
│   └── tui.sh          # TUI 루프 및 메뉴 시스템
├── conf/               # 에이전트별 CLI 설정 파일
├── templates/          # 프롬프트 및 리뷰 템플릿
└── .arena/runs/        # (자동생성) 실행 기록 및 산출물 보관소
```

## 🛠️ 사용 방법

### 기본 실행
터미널에서 인자 없이 실행하면 TUI 모드로 진입합니다.
```bash
./agent_arena.sh
```

### 리뷰 전용 가이드 워크플로우
1.  **리뷰 전용 모드** 선택
2.  **[Adhoc] 현재 브랜치로 새 리뷰 시작** 선택
3.  **1단계: Review-Pack**: 분석 및 프롬프트 생성
4.  **2단계: Open Review UI**: AI 리뷰 시작 (자동 모니터링 대기)
5.  **3단계: Integrated Review 확인**: 종합 결과 감상
6.  **4단계: Auto-Apply**: (선택) 제안 사항 자동 반영
7.  **5단계: Amend & Force Push**: 커밋 정리 및 자동 메시지 적용 푸시
8.  **6단계: Finish**: 종료 및 정리

## ⚙️ 설정 (Configuration)

`.env` 파일이나 환경 변수를 통해 동작을 제어할 수 있습니다.
- `ARENA_UI_MODE`: `auto`, `iterm2`, `tmux`, `none` 중 선택
- `AGENTS`: 사용할 에이전트 목록 (예: `claude,gemini,codex`)
- `AUTO_COMMIT`: `1` (임시 커밋 허용), `0` (금지)
